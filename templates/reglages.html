🎬 Emby

L'adresse de ton serveur Emby et sa clé API (Emby → Tableau de bord → Clés API). Sert à actualiser seulement le film ou la série dont tu viens de changer le poster.

🎞️ TheMovieDB

Sert à chercher les affiches (clé « API » de 32 caractères, ou « jeton d'accès » qui commence par eyJ).

📚 MouFlanga (mangas)

Pour envoyer un poster comme couverture d'une série de ta bibliothèque de mangas MouFlanga. Dans MouFlanga → ⚙️ Réglages → MouFloster, appuie sur « Générer une clé API », puis colle ici la clé et l'adresse de MouFlanga.

📨 Telegram

MouFloster te prévient s'il a planté ou redémarré, si une action échoue, ou quand un lot de posters est fini. Si une autre appli MouFl utilise déjà Telegram, ses réglages sont repris : il n'y a rien à saisir.
Régler un autre bot, un groupe ou un sujet
Dans ton groupe Telegram, ouvre le sujet de MouFloster, fais un appui long sur un message → « Copier le lien », colle-le ici : le groupe et le numéro du sujet se remplissent. Le bot doit être membre du groupe.
Détection automatique : écris « bonjour » dans le sujet puis appuie sur le bouton (impossible si le bot sert déjà à une autre application comme Jeedom : utilise alors le lien).

🎵 MouFlopening (génériques)

Après l'envoi d'un poster vers la médiathèque, si le film ou la série n'a pas encore de générique, MouFloster propose d'ouvrir MouFlopening directement sur ce titre. Mets les deux adresses : l'appli prend l'adresse locale quand tu es chez toi, l'adresse perso sinon. Vide = pas de proposition.

📁 Dossiers

Où se trouve ta médiathèque et où ranger les posters créés. L'appli redémarre après l'enregistrement (quelques secondes).
